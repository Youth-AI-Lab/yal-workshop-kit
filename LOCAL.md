# Run the workshop on your own computer (without a Codespace)

The usual way to run this kit is a **GitHub Codespace**: nothing to install, one link per pair
([README](README.md)). You can also open the **same kit on your own computer**, in a container: the
same image, the same commands (`workshop`, `replay`, `openwebui`…), the same results.

> ℹ️ **Note.** This path is for the facilitator or a technical partner, not for the participants
> during a session. If a Codespace works for you, use it.

**When you might want it:** your network blocks GitHub Codespaces; you have used up the free quota;
you want to keep your work without the 30-day deletion.

**How:** follow the guide
**[The workshop kit and the guides on your own computer](https://github.com/Youth-AI-Lab/yal-devcontainer-guide)**:
Docker and VS Code on Linux, macOS or Windows, then this kit opened in its container. Once it is
open, everything is as in a Codespace: `workshop-login`, then the [README](README.md).
