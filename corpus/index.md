# Official documents

The official documents the chatbot can use, as they were retrieved on 19 October 2026: web pages
(.html), PDF files and one Word file, never modified. Each one has a readable copy in `text/`,
with an OKF header (source, language, date): that copy is what you read, what mode B loads and
where mode C searches. The model never changes these files.
