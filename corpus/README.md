# corpus/ — what your chatbot knows (level 2)

Put text or Markdown files here, **one document per source**, with an explicit title and the
reference of the source on the second line. Example name: `10-brush-clearing-france.md`.

Group rules
- Typed and proofread text. No photos of handwritten notes, no unchecked OCR.
- Every figure must be traceable to the source quoted.
- If you don't have the source, don't write the figure.

Template of a document (see `00-template.md`):

    # <Title>
    Source: <full reference, link or document, date>
    Last checked: <date> by <who>

    <content, in short sentences>

Block B experiment: `90-contradiction.md` is a real official page whose figure contradicts
`10-eu-2025-wildfire-season.md`. Watch how the model reacts.

The documents marked "draft — needs human verification" were gathered from official pages and
must be checked by the facilitators before the session.
